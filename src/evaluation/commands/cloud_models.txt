# ArcShield cloud command templates
#
# These are first-run commands for missing cloud runs. Cleanup flags such as
# --resume and --retry-hard-cutoffs are intentionally omitted from first-run
# commands. Use the repair pattern at the bottom only after a run exists.
#
# Provider defaults used here:
# - Gemini: request-delay 20, max-tokens 512
# - Groq: request-delay 2, max-tokens 512
# - Cloudflare Qwen: request-delay 20, max-tokens 1024
# - Cloudflare DeepSeek: request-delay 120, max-tokens 1024
# - Cloudflare Gemma 4: use stable model prefix cloudflare2: with an explicit
#   --cloudflare-credentials primary|secondary override. Both profiles write to
#   the same canonical cloudflare_cf_google_gemma_4_26b_a4b_it model folder.
# - Cloudflare Grok 4.20 non-reasoning: request-delay 2, max-tokens 512
# - Cloudflare secondary account Kimi K2.6: use model prefix cloudflare2: request-delay 60, max-tokens 256 for the current partial run
# - Mistral: request-delay 2, max-tokens 512
#
# OpenAI GPT-family evaluation remains excluded for now because pilot runs
# consumed the completion budget as reasoning tokens without visible answers.
#
# Outputs are saved under:
# output/model_results/<model_slug>/<run_slug>/

====================
GENERAL CLOUD ATTACK RUN PATTERN
====================

First run:
python -m src.evaluation.run_attack_type_experiment --model MODEL_SPEC --attack-type "ATTACK TYPE" --condition both --request-delay DELAY --save-every 1 --max-tokens TOKENS

Resume existing run:
python -m src.evaluation.run_attack_type_experiment --model MODEL_SPEC --attack-type "ATTACK TYPE" --condition both --run-id single_attack_YYYYMMDD_HHMMSS --resume --request-delay DELAY --save-every 1 --max-tokens TOKENS

Resume a Gemma run with either Cloudflare account:
Keep --model cloudflare2:@cf/google/gemma-4-26b-a4b-it unchanged and add
--cloudflare-credentials primary or --cloudflare-credentials secondary.
Never run the same attack/run ID from both accounts concurrently.

Hard-cutoff cleanup only:
python -m src.evaluation.run_attack_type_experiment --model MODEL_SPEC --attack-type "ATTACK TYPE" --condition both --run-id single_attack_YYYYMMDD_HHMMSS --resume --retry-hard-cutoffs --request-delay DELAY --save-every 1 --max-tokens TOKENS

- Mistral MODEL_SPEC=mistral:mistral-small-latest DELAY=2 TOKENS=512

- Cloudflare DeepSeek MODEL_SPEC=cloudflare:@cf/deepseek-ai/deepseek-r1-distill-qwen-32b DELAY=120 TOKENS=1024
