# ArcShield local Ollama command templates

# Local models:
# - ollama:llama3.1:8b
# - ollama:qwen3:latest

# - ollama:mistral:latest
# - ollama:gemma3:latest
#
# These are first-run commands for missing local runs. Cleanup flags such as
# --resume and --retry-hard-cutoffs are intentionally omitted from first-run
# commands. Use the repair pattern at the bottom only after a run exists.
#
# Outputs are saved under:
# output/model_results/<model_slug>/<run_slug>/

====================
GENERAL LOCAL OLLAMA ATTACK RUN PATTERN
====================

First run:
python -m src.evaluation.run_attack_type_experiment --model MODEL_SPEC --attack-type "ATTACK TYPE" --condition both --save-every 1 --max-tokens TOKENS --model-timeout TIMEOUT

Resume existing run:
python -m src.evaluation.run_attack_type_experiment --model MODEL_SPEC --attack-type "ATTACK TYPE" --condition both --run-id single_attack_YYYYMMDD_HHMMSS --resume --save-every 1 --max-tokens TOKENS --model-timeout TIMEOUT

Hard-cutoff cleanup only:
python -m src.evaluation.run_attack_type_experiment --model MODEL_SPEC --attack-type "ATTACK TYPE" --condition both --run-id single_attack_YYYYMMDD_HHMMSS --resume --retry-hard-cutoffs --save-every 1 --max-tokens TOKENS --model-timeout TIMEOUT

Provider defaults:
- Llama 3.1 MODEL_SPEC=ollama:llama3.1:8b TOKENS=512 TIMEOUT=300
- Qwen3 MODEL_SPEC=ollama:qwen3:latest TOKENS=512 TIMEOUT=300
- DeepSeek R1 MODEL_SPEC=ollama:deepseek-r1:latest TOKENS=512 TIMEOUT=300
- Mistral MODEL_SPEC=ollama:mistral:latest TOKENS=512 TIMEOUT=300
- Gemma 3 MODEL_SPEC=ollama:gemma3:latest TOKENS=512 TIMEOUT=300
